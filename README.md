# Screw-Dislocated-Graphite-Thermal-Transport

This repository provides representative atomic structures and simulation input files for reproducing the tensile and cross-plane thermal transport calculations reported in our study.

## Contents

- `structures/`: Initial atomic configurations of screw-dislocated graphite.
- `tensile/`: Input files for tensile simulations.
- `NEMD/`: Input files for nonequilibrium molecular dynamics simulations.
- `potential/`: Interatomic potential.

## Simulation details

Simulation software: GPUMD

Interatomic potential: nep-GAP-carbon.txt

See the input files for the simulation parameters and boundary conditions.

## Reference

"Anomalous strain-dependent thermal conductivity in superelastic screw-dislocated graphites".
